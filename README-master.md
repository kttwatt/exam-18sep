## 1) Competency in OR — ข้อ 1–8 (8 ข้อ)

**แหล่ง:** `lecture-notes/2026-08-28-competency-in-or-exam-summary.md` (สไลด์ "สมรรถนะพยาบาลห้องผ่าตัด" 77 หน้า, พว.ธนพรรณ กุณาละสิริ)

**เข้าใจง่ายก่อน:** วิชานี้พูดถึงคำว่า "สมรรถนะ (Competency)" ในหลายมิติ — ลองนึกภาพว่า Competency คือ "ภูเขาน้ำแข็ง (Iceberg)" ส่วนที่โผล่พ้นน้ำมองเห็นง่าย (ความรู้ + ทักษะ) เป็นแค่ส่วนเล็ก ส่วนที่จมอยู่ใต้น้ำ (บุคลิกภาพ ค่านิยม แรงจูงใจ) ใหญ่กว่ามากและเป็นตัวกำหนดว่าคนคนนั้นจะทำงานได้ดีจริงหรือไม่ พยาบาลห้องผ่าตัดต้องมีสมรรถนะ 4 ด้านตามสมาคมวิชาชีพ และถูกจัดระดับความชำนาญตั้งแต่มือใหม่ (Level 1) ถึงผู้เชี่ยวชาญ (Level 5) โดยมีกรอบการประเมิน "ทักษะรอบด้าน" (non-technical skill) แยกตามบทบาท — จำง่ายๆ ว่าแต่ละวิชาชีพในห้องผ่าตัดมีกรอบชื่อไม่เหมือนกัน (วิสัญญีแพทย์=ANTS, ศัลยแพทย์=NOTSS, พยาบาลส่งเครื่องมือ=SPINTS) เหมือนแต่ละตำแหน่งมีเช็คลิสต์ทักษะของตัวเอง

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*นิยามและที่มาของ Competency*
- แนวคิดเกิดปี 1970 โดย **David McClelland** (20 พ.ค. 1917 – 27 มี.ค. 1998) นักจิตวิทยาชาวอเมริกัน ศึกษาว่าทำไมคนตำแหน่งเดียวกันมีผลงานต่างกัน [สรุป: competency-in-or-exam-summary]
- นิยาม McClelland: "บุคลิกลักษณะที่ซ่อนอยู่ภายในแต่ละบุคคลซึ่งผลักดันให้สร้างผลการปฏิบัติงานที่ดีหรือตามเกณฑ์ที่กำหนด" [สไลด์]
- นิยาม สนง. ก.พ. (2553): "กลุ่มของความรู้ ความสามารถ ทักษะ ทัศนคติที่จำเป็นในการทำงานได้อย่างมีประสิทธิภาพและประสิทธิผล" [สไลด์]
- แหล่งนิยามอื่น: Cambridge International Dictionary (1995), JCAHO (1993), AORN (1999) [สไลด์]
- **Iceberg Model** (McClelland–Spencer): ส่วนบนน้ำ (มองเห็นง่าย) = Knowledge + Skill; ส่วนใต้น้ำ (มองเห็นยาก) = Social Role, Self-Image, Trait, Motives [สไลด์]

*สมรรถนะพยาบาลห้องผ่าตัด 4 ด้าน (สมาคมพยาบาลห้องผ่าตัดแห่งประเทศไทย พ.ศ. 2554, ISBN 978-974-350-657-4)* [สไลด์]
1. ความปลอดภัยผู้ป่วย — ป้องกันบาดเจ็บเนื้อเยื่อจากสารเคมี/เครื่องจี้ไฟฟ้า/รังสี/การเคลื่อนย้าย/การจัดท่า
2. ร่างกาย — ป้องกันติดเชื้อ, การกำซาบเนื้อเยื่อ, อุณหภูมิกาย, สมดุลสารน้ำ/อิเลคโทรไลท์/กรดด่าง, ระบบหัวใจ-หลอดเลือด, จัดการความปวด
3. การตอบสนองพฤติกรรม — ให้ความรู้ผู้ป่วย/ญาติ, จริยธรรมและพิทักษ์สิทธิผู้ป่วย
4. ระบบสุขภาพ — ความเป็นวิชาชีพ, ปฏิบัติตามนโยบาย/มาตรฐานหน่วยงาน, สนับสนุนเป้าหมายองค์กร

*ประเภท Competency 3 ประเภท (กรอบของสไลด์นี้)* [สไลด์]
1. **Core Competency** — คุณสมบัติที่ทุกคนต้องมีเพื่อบรรลุความสำเร็จองค์กร เช่น ความรอบรู้องค์กร ความซื่อสัตย์ ความรับผิดชอบ ความคิดริเริ่มสร้างสรรค์
2. **Technical Competency** — แบ่งย่อย 3 ระดับ: **Basic** (พื้นฐานทุกคนต้องมี เช่น ให้เลือด/ป้องกันติดเชื้อ/จัดการความปวด) / **Specific** (เฉพาะกลุ่มผู้ป่วย เช่น ห้องผ่าตัดหัวใจทรวงอก) / **Advance** (บูรณาการคลินิก+เฉพาะทาง)
3. **Non-Technical Competency** — ทักษะรอบด้าน (ดูด้านล่าง)
- หมายเหตุแยกกรอบ: **สมรรถนะหลักภาครัฐ 5 ด้าน (ก.พ.)** เป็นคนละกรอบกับ Core/Technical/Non-Technical ห้ามปนกัน [สไลด์]

*โครงสร้างหน่วยผ่าตัด และ Benner / Proficiency Level* [สไลด์]
- โครงสร้าง 3 กลุ่มงาน: กลุ่ม 1 หน่วยผ่าตัด (Circulating/Scrub nurse), กลุ่ม 2 หน่วยพักฟื้น (PACU), กลุ่ม 3 หน่วยตรวจด้วยเครื่องมือพิเศษ
- **Benner (1984):** Novice 0-1y / Advance beginner 1-2y / Competent 2-3y / Proficient 3-5y / Expert 5y+
- **Proficiency Level (PL1-5)** — กรอบของหน่วยงานเอง **ไม่ผูกกับปีของ Benner โดยตรง**: PL1 ปฏิบัติตาม WI ถูกต้อง → PL2 รู้พยาธิสรีรภาพพื้นฐาน → PL3 ประเมิน/ตัดสินใจได้เองภายใต้พี่เลี้ยง → PL4 วางแผนดูแลองค์รวม/early detection → PL5 คาดการณ์/บูรณาการงานวิจัย/Best practice

*Non-technical skill: ANTS / NOTSS / SPINTS* [สไลด์]

| ระบบ | สำหรับ | หมวดหลัก |
|---|---|---|
| ANTS | วิสัญญีแพทย์ | Task Management / Team Working / Situation Awareness / Decision Making (4 หมวด) |
| NOTSS | ศัลยแพทย์ | Situation Awareness / Decision Making / Communication&Teamwork / Leadership (4 หมวด) |
| **SPINTS** | พยาบาลส่งเครื่องมือ | Situation Awareness / Communication&Teamwork / Task Management (**3 หมวดเท่านั้น**) |

- กรอบขยาย "Non-technical skills in Perioperative Nurses" (4 หมวดเต็ม — เพิ่ม Decision making and leadership) เป็นคนละกรอบกับ SPINTS ดั้งเดิม อย่าปนกัน [สไลด์]
- Non-technical skill เรียนรู้/ฝึกได้**หลังมีประสบการณ์ทำงานในห้องผ่าตัดแล้วเท่านั้น** [สไลด์]

*Scrub Nurse & Circulating Nurse (Level 1-5)* [สไลด์]
- **Scrub Nurse** L1 ปกป้องเขตปลอดเชื้อ/ดูผ่าตัดตั้งใจ → L2 อธิบายพยาธิสรีรภาพพื้นฐาน → L3 เตรียมเครื่องมือซับซ้อนภายใต้พี่เลี้ยง → L4 เตรียมยาเสี่ยงสูง/แก้ปัญหาวิกฤต (Bleeding) → L5 เป็นที่ปรึกษา/บูรณาการวิจัย
- **Circulating Nurse** L1 ทำความสะอาดห้องผ่าตัด/บันทึกข้อมูล → L2 ช่วยจัดท่า/ทำ Surgical safety checklist → L3 จัดท่าซับซ้อน/ควบคุมรุ่นน้อง → L4 บริหาร High Alert Drug → L5 บริหารจัดการปัญหาห้องผ่าตัด

*การประเมิน Competency* [สไลด์]
- วิธีประเมิน 6 วิธี: Audit, Certification/Training, CQI/PI, Interview, Observation, Testing
- เครื่องมือ: แบบวัดความรู้(ข้อสอบ), แบบวัดทัศนคติ, แบบวัดการปฏิบัติ
- ความถี่: **ปีละ 1 ครั้ง**
- แบบประเมินจริงใช้ระดับ 1-5 พร้อมคอลัมน์ **E/S/P/G** (Expect/Self/Preceptor/Gap)

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| David McClelland | 20 พ.ค. 1917 – 27 มี.ค. 1998, เริ่มแนวคิด Competency ปี 1970 [สไลด์] |
| สมรรถนะพยาบาลห้องผ่าตัด 4 ด้าน | ความปลอดภัยผู้ป่วย / ร่างกาย / ตอบสนองพฤติกรรม / ระบบสุขภาพ (สมาคมฯ พ.ศ. 2554) [สไลด์] |
| Technical Competency ย่อย | Basic / Specific / Advance [สไลด์] |
| Benner (1984) | Novice 0-1y / Advance beginner 1-2y / Competent 2-3y / Proficient 3-5y / Expert 5y+ [สไลด์] |
| SPINTS หมวด | 3 หมวด (ไม่ใช่ 4 เหมือน ANTS/NOTSS) [สไลด์] |
| ความถี่ประเมิน Competency | ปีละ 1 ครั้ง [สไลด์] |
| สมรรถนะหลักภาครัฐ (ก.พ. 2553) | 5 ด้าน: มุ่งผลสัมฤทธิ์/บริการที่ดี/สั่งสมความเชี่ยวชาญ/ยึดมั่นความถูกต้อง/ทำงานเป็นทีม [สไลด์] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. **SPINTS มี 3 หมวดเท่านั้น** — คนมักตอบผิดว่า 4 หมวดเพราะปนกับกรอบขยาย "Non-technical skills in Perioperative Nurses" [สไลด์]
2. Basic/Specific/Advance เป็นแค่การแบ่งย่อยของ **Technical Competency** ไม่ใช่ประเภทคู่ขนานกับ Core/Non-Technical [สไลด์]
3. PL (Proficiency Level) กับปีประสบการณ์ Benner เป็น**คนละกรอบ** ห้ามจับคู่ตัวเลขปีให้ตรงกัน [สไลด์]
4. ผู้ให้นิยาม Competency มีหลายแหล่ง (McClelland/ก.พ./Cambridge/JCAHO/AORN) — ระวังจำสลับ [สไลด์]
5. Scrub Nurse L1 เน้น "ปกป้องเขตปลอดเชื้อ" ส่วน Circulating Nurse L1 เน้น "ทำความสะอาดห้องผ่าตัด บันทึกข้อมูล" [สไลด์]
6. ความถี่การประเมิน Competency = **ปีละ 1 ครั้ง** ไม่ใช่ทุก 6 เดือน/2 ปี [สไลด์]
7. สมรรถนะหลักภาครัฐ 5 ด้าน (ก.พ.) ≠ สมรรถนะพยาบาลห้องผ่าตัด 4 ด้าน (สมาคมฯ) — คนละกรอบคนละที่มา [สไลด์]
8. หน่วยงาน/ปีที่กำหนดสมรรถนะ 4 ด้าน = สมาคมพยาบาลห้องผ่าตัดแห่งประเทศไทย **พ.ศ. 2554** [สไลด์]

## 2) ODS (One Day Surgery) — ข้อ 9–12 (4 ข้อ)

**แหล่ง:** `lecture-notes/2026-08-28-ods-patients.md` (พว.วราลักษณ์ บุญชัย, รพ.ศิริราช)

**เข้าใจง่ายก่อน:** ODS คือการผ่าตัดที่ผู้ป่วย "มาเช้า-กลับเย็น" ไม่ต้องนอนโรงพยาบาลข้ามคืน — ประโยชน์ชัดเจนคือลดความแออัดและประหยัดเงินทั้งฝั่งผู้ป่วยและโรงพยาบาล แต่การทำ ODS ให้ปลอดภัยต้องอาศัยกรอบคิด "2P Safety" (Patient & Personnel Safety) ซึ่งเป็นการเอาหลักความปลอดภัยมาตรฐาน 6 เรื่องมาปรับให้เข้มงวดขึ้นเป็นพิเศษ เพราะผู้ป่วยจะกลับบ้านเร็วมาก จึงต้องเผื่อเหตุ เช่น การทำ mark site ให้ชัดตั้งแต่ก่อนผ่าตัด และระบบติดตามอาการหลังกลับบ้านที่ต้องแน่นหนา

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*นิยาม* [สไลด์]
- **ODS** = รับผู้ป่วยเข้ารับการผ่าตัด/หัตถการที่เตรียมการไว้แล้ว และให้กลับบ้าน**วันเดียวกับวันที่เข้ารับการรักษา** — อยู่ใน รพ. **ตั้งแต่ 2 ชั่วโมง ถึงไม่เกิน 24 ชั่วโมง**
- **MIS** = ผ่าตัดแผลเล็ก/ผ่าตัดผ่านกล้อง ลดปวดแผล ฟื้นตัวเร็วกว่า
- ผลลัพธ์ ODS ปี 2561–2564: ทำหัตถการ **41,532 ราย**, ลดค่าใช้จ่ายภาคประชาชน **66,451,200 บาท**, ประมาณการค่าใช้จ่าย/คน/วัน = **800 บาท** (อาหาร 200 + เดินทาง 200 + ค่าเสียเวลา 400), ลดวันนอน รพ. **83,064 วัน**

*2P Safety (Patient & Personnel Safety) — 6 องค์ประกอบ* [สไลด์]

| องค์ประกอบ | ใจความสำคัญ |
|---|---|
| Surgical Safety Checklist | 3 ระยะ: **Sign in** (ก่อนยาระงับความรู้สึก) → **Time out** (ก่อนลงมีด) → **Sign out** (ก่อนออกจากห้องผ่าตัด); หลัก **Zero defect** — cross check ทีละขั้น ข้ามขั้นไม่ได้ |
| SSI prevention | superficial incisional/deep incisional **ภายใน 30 วัน** vs organ/space **ภายใน 30 วัน หรือ 90 วัน** (ถ้ามี implant); เฝ้าระวังเชิงรุกที่ **24, 48, 72 ชม.** |
| Safe Anesthesia | Pre-anesthetic evaluation ก่อนผ่าตัดสำคัญสุด; การจำหน่ายใช้ scoring ตามราชวิทยาลัยวิสัญญีฯ |
| Safe Operating Room | ระบบระบายอากาศ **20 ACH (air change per hour)**, อุณหภูมิ **22–24 °C** |
| Acute Pain Management | Acute pain ≤3 เดือน ส่วนใหญ่ nociceptive; ใช้ multimodal + preventive analgesia แบบ procedure-specific |
| Security & Privacy of Information | PDPA, Informed consent ชัดเจน, telehealth/Line ต้องวางระบบความปลอดภัยข้อมูล |

*การจัดการการพยาบาลผู้ป่วย ODS & MIS 3 ระยะ* [สไลด์]
1. ก่อนผ่าตัด — งดน้ำ-อาหาร, ตรวจร่างกาย/lab, พบวิสัญญี, ให้ความรู้การปฏิบัติตัวหลังผ่าตัด
2. ระหว่างพักฟื้นใน รพ. — ประเมินปวด/การเคลื่อนไหว, จัดการปวด, ดูแลแผล
3. หลังจำหน่าย — ติดตามผ่าน Telehealth หรือนัดตรวจ

*บทบาทพยาบาลแต่ละหน่วย (ศิริราช)* [สไลด์]
- พยาบาลผู้ประสานงาน 11 บทบาท: สร้างสัมพันธภาพ/ประเมินความเสี่ยง → **โทร 7–10 วันก่อนผ่าตัด** (เตรียมสิทธิรักษา/งดยาละลายลิ่มเลือด) → **โทร 1–3 วันก่อนผ่าตัด** → **โทรติดตาม post-op day 0, day 1, day 2** → ลง registry → บันทึกทางการพยาบาล
- พยาบาล WR: ซักประวัติ/ลง Perioperative Nursing Record/ตรวจเอกสารยินยอม
- พยาบาล OR: รับข้อมูลจาก WR/ทำ Sign in–Time out–Sign out/ส่งต่อข้อมูลให้ RR
- พยาบาล RR: ประเมินแรกรับ/จัดการปวด/**จำหน่ายเมื่อถึงเกณฑ์ (Discharge criteria)**

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| ระยะเวลาอยู่ รพ. ของ ODS | 2–24 ชั่วโมง [สไลด์] |
| จำนวนผู้ป่วย ODS (2561–2564) | 41,532 ราย [สไลด์] |

## 3) MIS (Beyond Routine: EBP in MIS) — ข้อ 13–20 (8 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-02-mis-exam-summary.md` (พว.วริศรา ตุวยานนท์, Session B)

**เข้าใจง่ายก่อน:** วิชานี้คือ "ความปลอดภัยของผู้ป่วยระหว่างผ่าตัดผ่านกล้อง (MIS)" — จำง่ายๆ ด้วย **5 ความเสี่ยงหลัก**: ท่าจัดผ่าตัด, แผลกดทับ, DVT, ภาวะแทรกซ้อนจากลมที่เป่าเข้าท้อง (pneumoperitoneum), และอุณหภูมิกายต่ำ ตัวเลขวิจัยเยอะมากเพราะวิทยากรอ้างงานวิจัยเฉพาะเจาะจงในแต่ละหัวข้อ ข้อสอบชอบเอาตัวเลขพวกนี้มาถามตรงๆ เช่น แรงดันลดลงเท่าไรต่อการยกขา 1 ฟุต หรือ OR (odds ratio) ของปัจจัยเสี่ยงแต่ละตัว ต้องจำให้แม่นเพราะคล้ายกันแต่ค่าต่างกันมาก

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*Outline 5 หัวข้อ* [สไลด์]: New Technology in MIS · Knowledge Integration to MIS · Inventory Management in MIS · Nursing Management in Laparoscopic surgery · MIS & ERAS concept Integration

*เทคโนโลยีใหม่ใน MIS* [สไลด์]: Endoscopic Imaging, Robotic Surgery (Enhanced precision/Improved ergonomics/Remote surgery), Virtual Reality Simulation, Artificial Intelligence — ICG & Fluorescence Imaging ใน Lap Hepatectomy ช่วย improved tumor identification, accurate segmental resection, enhances safety

*daVinci Xi & Inventory* [สไลด์]: ประกอบด้วย Surgeon console, Patient cart, Vision cart (คู่แข่ง = **HUGO™ RAS System**); Robotic instrument cannula 8 mm, seal 5-8 mm; endoscope ห้ามใช้ warming liquid เกิน 55°C; Reprocessing ใช้ Low-temperature sterilization (Hydrogen peroxide plasma, E.O.) หรือ Steam sterilization

*Purpose of Management in Laparoscopic surgery (AORN, 2020)* [สไลด์]: (1) Reduce risk to patient and perioperative team (2) Managing distention media and irrigation (3) Maintain Lap instrument's function

*Patient safety concern during MIS — 5 ข้อหลัก* [สไลด์]: positioning · pressure injury · DVT prevention · pneumoperitoneum complications · hypothermia

*Positioning & Pressure injury* [สไลด์]
- Extreme positioning เพิ่ม risk of CO2 retention, intracranial pressure, intraocular pressure, mean arterial pressure
- **Lithotomy elevation:** ทุก 1 ฟุตของการยกข้อเท้าเหนือ aorta → ankle systolic/diastolic pressure ลดลง **~20 mmHg** → ลด capillary perfusion → risk of pressure injury
- Super obesity: reverse Trendelenburg **12-15°**, instrument ยาวขึ้น **43-44 cm**, safety strap พิเศษ
- OR bed mattress pad หนา **8 cm และ 4.5 cm**; Room Temp แนะนำ **20-22°C**
- Bundle ป้องกัน pressure injury 4 องค์ประกอบ: Maintenance of normothermia, Special padding, Positioning devices, Polyurethane foam dressing

*DVT/VTE prevention* [สไลด์]
- Risk (AORN 2017): Laparoscopic + Lithotomy + **Operative time > 3 ชั่วโมง** + old age/obesity
- Intervention: sequential pneumatic compression device
- Contraindication ของ mechanical VTE prophylaxis (NCCN 2015): platelet < 20,000, แผลเปิด/gangrene/recent skin graft ที่ขา, severe arteriosclerosis, massive edema จาก CHF, extreme leg deformity, DVT/PE ใน 6 เดือนก่อนหน้า

*Hypothermia* [สไลด์]
- ผลกระทบ: Shivering, เพิ่ม oxygen consumption/myocardial workload; ปัจจัย: Insufflated CO2 temp 15-22°C
- **งานวิจัยหลัก (Wongyingsinn M, et al. BMC Anesthesiology 2023;23:137):** n=742, postoperative hypothermia **11.9%**; กลุ่ม monitor intraop core temp (n=117) พบ intraop hypothermia **73.5%**; ปัจจัยสัมพันธ์ — ASA III-IV (**OR=1.78**), preoperative hypothermia (**OR=17.99**)
- **forced-air warming blankets "ไม่แนะนำ"** เพราะเพิ่มความเสี่ยงติดเชื้อ (Koc BB, et al. Orthop Nurs 2017)
- warmed & humidified CO2 → core temp เพิ่มเฉลี่ย **0.3°C** (Dean M, et al. 2017)
- Siriraj audit keep core temp >36°C: ปี 2567=69.84%; เม.ย.-มิ.ย.2568=82.61% (38/46 ราย)

*Distention media & Pneumoperitoneum* [สไลด์]
- Solubility (ml/100ml น้ำ): CO2=170, N2O=130, Argon/Helium=6
- **Support combustion / Hazardous to personnel: มีแค่ Nitrous oxide (N2O) เท่านั้น** — CO2 และ Argon/Helium ไม่ใช่ทั้งคู่
- ETCO2 ปกติ **35-45 mmHg**
- อาการ CO2 embolism: ความดันเลือดลดฮวบ, ETCO2 ลดฮวบ, O2 sat ลดเร็ว; Intervention: หยุด CO2 insufflation, Trendelenburg, NSS irrigation, ใส่ central line

*Instrument function/insulation failure* [สไลด์]: การศึกษา Montero et al. 2010 — ตรวจ laparoscopic instruments ใช้ซ้ำ **165 ชิ้น** พบ insulation failure **19%**

*MIS & ERAS Integration* [สไลด์]: Siriraj ERAS 10 modules — Colorectal, Gynecology, Upper GI, Liver, Pancreas, Spine, Acute hip fracture, CVT, rAAA, Liver Transplant, Cystectomy

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| Lithotomy elevation effect | ทุก 1 ฟุตเหนือ aorta → ankle pressure ลด ~20 mmHg [สไลด์] |
| Super obese reverse Trendelenburg | 12-15° [สไลด์] |
| Super obese instrument length | 43-44 cm [สไลด์] |
| OR bed mattress pad | 8 cm และ 4.5 cm [สไลด์] |
| Room temp แนะนำ | 20-22°C [สไลด์] |
| DVT risk operative time | > 3 ชั่วโมง [สไลด์] |
| Hypothermia study n | 742 (postop 11.9%), 117 (intraop 73.5%) [สไลด์] |
| OR ASA III-IV / preop hypothermia | 1.78 / 17.99 [สไลด์] |
| Warmed/humidified CO2 → core temp | +0.3°C [สไลด์] |
| ETCO2 ปกติ | 35-45 mmHg [สไลด์] |
| Solubility CO2/N2O/Argon-Helium | 170/130/6 ml/100ml [สไลด์] |
| Insulation failure (Montero 2010) | 165 ชิ้น, พบ failure 19% [สไลด์] |
| Siriraj Modules ERAS | 10 modules [สไลด์] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. Lithotomy 1 ฟุต → **~20 mmHg** (ไม่ใช่ 10 mmHg) [สไลด์]
2. เฉพาะ **N2O** เท่านั้นที่ support combustion + hazardous ต่อบุคลากร — CO2 ไม่ใช่ [สไลด์]
3. OR ของปัจจัยเสี่ยง hypothermia: ASA III-IV = **1.78**, preoperative hypothermia = **17.99** — สลับกันบ่อย [สไลด์]
4. forced-air warming **ไม่แนะนำ** เพราะเพิ่มความเสี่ยงติดเชื้อ (Koc BB 2017) [สไลด์]
5. DVT risk เวลาผ่าตัด > **3 ชั่วโมง** (ไม่ใช่ 2 หรือ 4) [สไลด์]
6. ETCO2 ปกติ **35-45 mmHg** [สไลด์]
7. Insulation failure = **19%** จากตรวจ 165 ชิ้น (Montero) [สไลด์]
8. Patient safety concern 5 ข้อ ต้องจำครบ: positioning, pressure injury, DVT, pneumoperitoneum, hypothermia [สไลด์]

## 4) URO anatomy — ข้อ 27–34 (8 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-01-uro-anatomy-exam-summary.md` (อ.พญ.สรรพพร บุญวงศ์, สไลด์ 117 หน้า)

**เข้าใจง่ายก่อน:** วิชานี้คือกายวิภาคของระบบทางเดินปัสสาวะและระบบสืบพันธุ์ชายแบบ "ไล่ตามเส้นทาง" — เริ่มจากไต (กรองเลือดเป็นปัสสาวะ) → ท่อไต (มีจุดตีบธรรมชาติ 3 จุด ที่นิ่วมักติด) → กระเพาะปัสสาวะ (ทำงาน 2 โหมดสลับกัน: เก็บ กับ ถ่าย) → ต่อมลูกหมาก/ท่อปัสสาวะ (มี sphincter 2 ชั้นควบคุมการกลั้น) → อัณฑะ (ผลิตอสุจิ) จำหลักสำคัญคือ "ระบบประสาทซิมพาเทติกช่วยเก็บกัก, พาราซิมพาเทติกช่วยถ่าย" ซึ่งตรงข้ามกับที่คนมักเข้าใจสามัญ และจุด landmark ผ่าตัด TURP (verumontanum, bladder neck) ที่อาจารย์เน้นเป็นพิเศษเพราะเชื่อมกับหัตถการจริง

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*กายวิภาคไต* [สไลด์ หน้า 5–12]
- ไตอยู่ retroperitoneal ล้อมรอบด้วย liver, adrenal, pancreas, spleen, colon, duodenum
- แนวไตแต่ละข้างทำมุม **30° จากแนวตั้ง** เทียบกับกระดูกสันหลัง T12–L5
- ชั้นห่อหุ้มไต: Kidney → Fat layer → **Gerota's fascia** (ห่อหุ้ม**ทั้งไตและต่อมหมวกไต**)
- ทางเดินปัสสาวะภายในไต: **Nephron → Papillary duct → Minor calyx → Major calyx → Renal pelvis → Ureter → Bladder**

*Nephron และสรีรวิทยาการสร้างปัสสาวะ* [สไลด์ หน้า 13–18]
- 3 ขั้นตอน: **Glomerular Filtration → Tubular Reabsorption → Tubular Secretion**
- ความดันกรองที่ glomerulus: Glomerular hydrostatic **55 mmHg** − Blood colloid osmotic **30 mmHg** + Capsular hydrostatic **15 mmHg** → Net outward **10 mmHg**
- ปริมาตรปัสสาวะเฉลี่ย/วัน (ผู้ใหญ่) = **1.4 ลิตร**

*กายวิภาคท่อไต* [สไลด์ หน้า 19–23]
- จุดตีบธรรมชาติ 3 จุด: **Ureteropelvic junction, Crossing iliac vessels/pelvic brim, Traversing bladder wall**
- ท่อไตส่วนปลายต่อเนื่องเป็น **Waldeyer's sheath** → ขยายเป็น **superficial trigone (white zone)** และ **deep trigone**

*กระเพาะปัสสาวะ* [สไลด์ หน้า 24–36]
- ผนัง (ในสู่นอก): Urothelium (Umbrella/Intermediate/Basal cells) + Lamina propria = Mucosa → Submucosa → Detrusor muscle → Adventitia
- Stages มะเร็งกระเพาะปัสสาวะ: **Stage 0 → I → II → III → IV**
- 2 phase การทำงาน: **Storage (filling)** — low pressure, continence; **Voiding** — complete emptying, no obstruction
- เส้นประสาทควบคุม:

| ระบบประสาท | เส้นประสาท/ระดับไขสันหลัง | ผลที่ตัวรับ |
|---|---|---|
| Sympathetic | Hypogastric n. (**T11–L2**) | คลาย detrusor (β-AR) + หด bladder neck/EUS (α1-AR) → **เก็บกัก** |
| Parasympathetic | Pelvic n. (**S2–S4**) | หด detrusor (M3/M2/P2X1) → **ถ่ายปัสสาวะ** |
| Somatic | Pudendal n. | หด EUS (nicotinic) |

- Filling: **Bladder relax + Sphincter contract**; Voiding: **Bladder contract + Sphincter relax**

*ต่อมลูกหมาก & seminal vesicle* [สไลด์ หน้า 37, 41]
- Zones: Central, Transition (BPH เกิดที่นี่), Peripheral (มะเร็งมักเกิดที่นี่), Anterior fibromuscular stroma
- **Colliculus seminalis** = landmark สำคัญ — resection ต้องทำเหนือจุดนี้เพื่อไม่บาดเจ็บ external urethral sphincter

*ท่อปัสสาวะชาย-หญิง* [สไลด์ หน้า 38–43]
- ชาย: Prostatic urethra → Membranous urethra → Spongy (penile) urethra
- Sphincter: **Bladder neck (internal)** และ **External urethral sphincter** ที่ urogenital diaphragm
- **Levels of Vaginal Wall Support (DeLancey 1992):** Retropubic space, Pubocervical fascia, Vesicovaginal space, Cardinal ligament, Rectovaginal space, Sacro-uterine ligament

*อัณฑะ, epididymis, spermatogenesis* [สไลด์ หน้า 44–48]
- เส้นทาง: Testis → Epididymis → Vas deferens → Seminal vesicle → Ejaculatory duct → Prostatic urethra → Urethra → Penis
- มโนมนีมอนิก **"SEVEN UP"**: **S**eminiferous tubule, **E**pididymis, **V**as deferens, **E**jaculatory duct, **N**(none), **U**rethra, **P**enis
- **Seminal vesicle ผลิตของเหลว 65–75% ของน้ำอสุจิทั้งหมด** (มี fructose + prostaglandins)
- Sertoli cell (ใน seminiferous tubule) และ Leydig cell (interstitium)

*การผ่าตัดที่เชื่อมกับกายวิภาค* [สไลด์ หน้า 66–83]
- **Male continence mechanism:** Internal sphincter ที่ **bladder neck**; External sphincter ที่ **membranous urethra** — **TUR-P มักทำลาย internal sphincter เป็นปกติของหัตถการ** ต้องระวังไม่บาดเจ็บ external sphincter
- **TURP landmark:** Verumontanum (**distal landmark**), Bladder neck (**proximal landmark**), Surgical capsule (ระดับความลึก)
- Radical prostatectomy (ตัดทั้งต่อม+seminal vesicle) vs Partial (HoLEP/TURP — ตัดเฉพาะ transitional zone)
- Radical cystectomy: ตัดกระเพาะปัสสาวะพร้อม **prostate (ชาย)** หรือ **anterior vagina/uterus (หญิง)**

*คำย่อ/สายสวน* [สไลด์ หน้า 85–117]: PCN (Percutaneous nephrostomy), DJ stent (Double J), SPC (Suprapubic cystostomy — ขนาดปกติ **16 Fr หรือ 18 Fr**)

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| มุมแนวไตจากแนวตั้ง | 30° [สไลด์ หน้า 6] |
| Glomerular hydrostatic pressure | 55 mmHg [สไลด์ หน้า 16] |
| Blood colloid osmotic pressure | 30 mmHg [สไลด์ หน้า 16] |
| Capsular hydrostatic pressure | 15 mmHg [สไลด์ หน้า 16] |
| Net filtration pressure | 10 mmHg [สไลด์ หน้า 16] |
| ปริมาตรปัสสาวะเฉลี่ย/วัน | 1.4 ลิตร [สไลด์ หน้า 18] |
| Seminal vesicle สัดส่วนน้ำอสุจิ | 65–75% [สไลด์ หน้า 46] |
| Sympathetic (hypogastric n.) ระดับไขสันหลัง | T11–L2 [สไลด์ หน้า 34] |
| Parasympathetic (pelvic n.) ระดับไขสันหลัง | S2–S4 [สไลด์ หน้า 34] |
| TUR syndrome เกณฑ์ต่อม | > 45 g [สไลด์ หน้า 81] |
| TUR syndrome เกณฑ์ความสูงถุงน้ำล้าง | > 60 cm จาก pubic symphysis [สไลด์ หน้า 81] |
| TUR syndrome เกณฑ์เวลาตัด | > 90 นาที [สไลด์ หน้า 81] |
| ขนาด SPC catheter | 16 Fr หรือ 18 Fr [สไลด์ หน้า 115] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. Internal sphincter (bladder neck, sympathetic) vs External sphincter (membranous urethra, pudendal) — TUR-P ทำลาย **internal** ไม่ใช่ external [สไลด์ หน้า 69–70]
2. TURP landmark: **Verumontanum = distal**, **Bladder neck = proximal** [สไลด์ หน้า 71]
3. Filling: Bladder relax+Sphincter contract; Voiding: Bladder contract+Sphincter relax — สลับกันง่าย [สไลด์ หน้า 36]
4. Autonomic ทำงาน**ตรงข้าม**สามัญสำนึก: Sympathetic (T11-L2) → เก็บกัก; Parasympathetic (S2-S4) → ถ่ายปัสสาวะ [สไลด์ หน้า 34]
5. **Gerota's fascia** ห่อหุ้มทั้งไต**และ**ต่อมหมวกไต [สไลด์ หน้า 7]
6. **Seminal vesicle** (ไม่ใช่ prostate) ผลิตของเหลวส่วนใหญ่ของน้ำอสุจิ (65–75%) [สไลด์ หน้า 46]
7. Trigone แบ่ง superficial (white zone) กับ deep trigone ต่อเนื่องจาก Waldeyer's sheath [สไลด์ หน้า 22]
8. TUR syndrome = hypervolemia + dilutional hyponatremia ร่วมกัน ไม่ใช่แค่ hyponatremia [สไลด์ หน้า 81]

## 5) Periop URO — ข้อ 35–40 (6 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-02-periop-URO.md` (พว.ญาณนันท์ รัตนธีรวิเชียร, "Advanced Perioperative Nursing in Urology Surgery")

**เข้าใจง่ายก่อน:** วิชานี้ต่อยอดจาก URO anatomy มาสู่ "การพยาบาลจริง" — เอาความเสี่ยงหลักๆ ที่พบในผ่าตัดทางเดินปัสสาวะมาจัดกลุ่มเป็น 4 ชนิดวิธีผ่าตัด (Open/Lap/Robotic/Endoscopic) คูณกับ 3 ท่าจัดผ่าตัด (Lithotomy/Lateral/Prone) แล้วจับคู่ว่าแต่ละท่าเสี่ยงอะไร จากนั้นมี 5 ภาวะแทรกซ้อนเฉพาะที่ต้องป้องกัน (Uro sepsis, VTE, Pressure injury, TURP syndrome, Hypothermia) — ข้อสอบเน้นการจับคู่ "ท่า → หัตถการ → ความเสี่ยงเฉพาะ" และตัวเลขจากงานวิจัยที่สไลด์อ้างอิง

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*ภาพรวมวิธีผ่าตัด 4 ชนิด* [สไลด์]

| วิธีผ่าตัด | ลักษณะ | ความเสี่ยงหลัก |
|---|---|---|
| Open Surgery | แผลใหญ่ | ติดเชื้อ, เสียเลือด |
| Laparoscopic | แผลเล็ก+กล้อง | pneumoperitoneum, nerve injury จากท่า, gas embolism |
| Robotic | หุ่นยนต์ช่วย | ระบบขัดข้อง (malfunction) |
| Endoscopic | เข้าทางช่องธรรมชาติ (เช่น TURP) | เยื่อบุฉีกขาด/ทะลุ, UTI |

*ความเสี่ยงจากท่าจัดผ่าตัด — จับคู่ให้แม่น* [สไลด์]

| ท่า | ใช้กับหัตถการ | ความเสี่ยงหลัก |
|---|---|---|
| **Lithotomy** | TUR, URS, RIRS | **peroneal nerve injury**, circulatory issues ที่ขา |
| **Lateral/Kidney position** | Nephrectomy | **respiratory compromise**, **ulnar nerve injury** |
| **Prone** | PCNL | **pressure ulcers** ที่หน้าอก-หน้าท้อง, **ocular complications** (corneal abrasion) |

*Uro Sepsis* [สไลด์]: ต้องระบุผู้ป่วยกลุ่มเสี่ยงสูงเพื่อรักษาแต่เนิ่นๆ — monitor vital signs (T, HR, BP), blood cultures, surveillance strategies; อ้างอิง Croghan SM, et al. (2023) BJU Int 132:531–540 (n=120)

*VTE* [สไลด์]
- Patient-related: age, obesity, smoking, cancer, ประวัติ VTE เดิม; Procedure-related: ชนิด/ระยะเวลาผ่าตัด, tissue manipulation; Medication-related: hormonal therapy, chemotherapy
- **Incidence VTE หลัง urology surgery = 1–10%**
- **IPC (Intermittent Pneumatic Compression) ลด asymptomatic+distal DVT ได้ 60% และ proximal DVT ได้ 50%** (Roderick P, Ferris G, Wilson K, 2005)

*Pressure Injuries* [สไลด์]: ปัจจัยเสี่ยง — Prolonged Immobility, Inadequate Padding, Compromised Circulation (DM, PAD), Skin Conditions เดิม; อ้างอิง Aldughayfiq B, et al. (2023) Healthcare 11:1222

*TURP Syndrome* [สไลด์]
- สาเหตุ: การดูดซึม irrigation fluid มากเกิน → fluid overload + electrolyte imbalance
- อาการ: hyponatremia, confusion, hypertension/hypotension, visual disturbances, seizures
- ป้องกัน: จำกัดการดูดซึม irrigation fluid, ใช้ isotonic solution, ตรวจ electrolyte เป็นระยะ

*Hypothermia* [สไลด์]: อาการ shivering, decreased HR, low BP; ผลกระทบ — เพิ่มความเสี่ยงติดเชื้อ, ชะลอแผลหาย, ยืดระยะฟื้นตัว; ป้องกันด้วย forced-air warming blanket + heated IV fluids (สไลด์วิชานี้ระบุใช้ได้ — ต่างจากหัวข้อ MIS ที่บอกไม่แนะนำ ให้ยึดตามบริบทวิชาที่ถาม)

*ภาวะแทรกซ้อนจากแก๊สในการผ่าตัดผ่านกล้อง* [สไลด์]
- CO2 Subcutaneous Emphysema: PaCO2/ETCO2 สูงขึ้น → หยุดผ่าตัดชั่วคราว
- Pneumothorax/Pneumomediastinum/Pneumopericardium: จาก high IAP → ปิด N2O, ลด IAP ให้น้อยที่สุด
- **Gas Embolism:** tachycardia, arrhythmia, hypotension, ECG change → หยุด CO2, ปิด N2O, O2 100% + hyperventilation, **จัดท่าศีรษะต่ำ ตะแคงซ้าย (left lateral, head-down)**

*เทคนิคป้องกัน VTE — Mechanical Prophylaxis* [สไลด์]: Compression Stockings, Intermittent Pneumatic Compression (IPC), VTE (IVC) Filters

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| Incidence VTE หลัง urology surgery | 1–10% [สไลด์] |
| IPC ลด asymptomatic+distal DVT | 60% [สไลด์] |
| IPC ลด proximal DVT | 50% [สไลด์] |
| ท่า TUR/URS/RIRS | Lithotomy → peroneal nerve + circulatory [สไลด์] |
| ท่า Nephrectomy | Lateral/Kidney → respiratory + ulnar nerve [สไลด์] |
| ท่า PCNL | Prone → pressure ulcer + ocular [สไลด์] |
| งานอ้างอิง Uro sepsis | Croghan et al. 2023, BJU Int 132:531–540, n=120 [สไลด์] |
| งานอ้างอิง Pressure ulcer | Aldughayfiq et al. 2023, Healthcare 11:1222 [สไลด์] |
| ท่าจัดการ gas embolism | ศีรษะต่ำ ตะแคงซ้าย [สไลด์] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. จับคู่ท่า-หัตถการ-ความเสี่ยงให้แม่น: Lithotomy→peroneal, Lateral→ulnar+respiratory, Prone→pressure+ocular [สไลด์]
2. Incidence VTE urology surgery = **1–10%** (ช่วงกว้าง จำเป็นช่วงไม่ใช่ตัวเลขเดียว) [สไลด์]
3. IPC ลด distal DVT **60%** vs proximal DVT **50%** — ตัวเลขคนละค่ากัน [สไลด์]
4. Gas embolism ต้องจัดท่า**ศีรษะต่ำ ตะแคงซ้าย** (ไม่ใช่ศีรษะสูง) เพื่อดักแก๊สไว้ใน right atrium ไม่ให้เข้าสู่ pulmonary circulation [สไลด์][จริง]
5. TURP syndrome คืออาการจาก fluid overload+electrolyte imbalance (hyponatremia, confusion, BP ผิดปกติ, visual disturbance, seizures) — จำอาการให้ครบ [สไลด์]
6. หัวข้อนี้สไลด์ระบุใช้ forced-air warming ป้องกัน hypothermia ได้ (ต่างจากหัวข้อ MIS ที่บอกไม่แนะนำ) — ต้องอ่านคำถามให้ดีว่าถามวิชาไหน [สไลด์]

## 6) Lower Extremity — ข้อ 41–48 (8 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-04-lower-extremity.md` (รศ.นพ.ทศหาญ รุ่งโรจน์, สไลด์ 14 หน้า)

**เข้าใจง่ายก่อน:** วิชานี้คือกระดูกหักที่ขา ตั้งแต่หลักการจัดการทั่วไป (Recognition → Reduction → Retention → Rehabilitation) ไปจนถึงภาวะแทรกซ้อนเฉพาะ (หลอดเลือด, compartment syndrome, ลิ่มเลือด, ไขมันอุดตัน) แล้วไล่ลงมาตามตำแหน่งกระดูก (เชิงกราน→สะโพก→ต้นขา→เข่า→หน้าแข้ง→ข้อเท้า→เท้า) จุดตายตัวที่ต้องจำคือ "ตัวเลขเกณฑ์การตัดสินใจ" เช่น ABI, ความดัน compartment, เวลาที่ต้อง reduce hip dislocation — ตัวเลขพวกนี้ออกสอบตรงๆ บ่อยมาก

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*หลักการจัดการกระดูกหัก* [สไลด์]: Recognition (ATLS, Hx/PE, Radiograph) → Reduction (close/open) → Retention (external: cast/traction/ex-fix; internal: K-wire/plate+screw/nail) → Rehabilitation (ROM→stretching→strengthening)

*Open fracture — Gustilo-Anderson* [สไลด์]
- Converting factors (ตัวแปรที่ทำให้ grade สูงขึ้น): ปนเปื้อน (soil/dirty water/bites), > 12 ชั่วโมง, high energy, bone loss, segmental fracture, crush/degloving injury, compartment syndrome, ต้อง flap coverage
- Antibiotic: ฉีด**ไม่เกิน 24 ชม.**หลังบาดเจ็บ; Type I,II → **1st gen cephalosporin**; Type III → **+aminoglycoside**; ดินปนเปื้อน → **+Penicillin 2 ล้าน unit q 4 hr**

*Vascular injury* [สไลด์]
- Upper extremity มี collateral circulation มากกว่า → **lower extremity ไวต่อ ischemia กว่า** [จริง]
- **Hard signs** (ต้องผ่าตัดสำรวจโดยตรง): **6P** = Pulselessness, Pallor, Paresthesia, Pain, Paralysis, Poikilothermia + massive bleeding, expanding hematoma, palpable thrill, audible bruit
- Soft signs: hematoma เล็กไม่ pulsatile, neurologic deficit จากเส้นประสาทข้างเคียง
- **ABI = Doppler pressure ขาบาดเจ็บ ÷ brachial artery; ABI > 0.9 = ปกติ, < 0.9 = ผิดปกติ**; หาค่าไม่ได้ → angiography
- Priority: Stable ortho injury → **vascular ก่อน**; Unstable → **orthopaedic ก่อน**; Unstable+delayed → **temporary shunting**

*Compartment syndrome* [สไลด์]
- Signs: ปวดเมื่อคลำ compartment, ตึง/บวม, passive stretch เจ็บมาก, sensory deficit, กล้ามเนื้ออ่อนแรง; Symptoms: ปวดมากเกินสัดส่วน (pain out of proportion)
- Normal pressure 0–8 mmHg; **ΔP = DBP − compartment pressure ≤ 30 mmHg** บ่งชี้ภาวะผิดปกติ; MAP = DBP + ⅓ pulse pressure
- บ่งชี้ monitor เมื่อผู้ป่วย unconscious/unreliable หรือ clinical findings ไม่ชัดเจน
- รักษา: ปลด constrictive dressing → bivalve cast → **fasciotomy** → stabilize fracture

*Thromboembolism (DVT/PE)* [สไลด์]: Risk factors — ประวัติ DVT/PE, malignancy, hemiplegia, BMI>30, CHF; Clinical — calf/thigh บวม, **Homans' sign**; Diagnosis — venography, duplex U/S

*Fat embolism syndrome (FES)* [สไลด์]
- Fat emboli พบ ~90% หลัง major trauma; FES เกิด **2–5%**, อาการภายใน **24–72 ชม.** หลังบาดเจ็บ
- **เกณฑ์ Gurd — วินิจฉัย = 2 major หรือ 1 major + 4 minor:** Major = Petechial rash, respiratory insufficiency, cerebral involvement, tachycardia; Minor = fever, retinal changes, jaundice, renal signs, thrombocytopenia, anemia, high ESR
- Treatment: supportive + intensive monitoring + **early fracture stabilization**

*Pelvic injury* [สไลด์]: Hemorrhage control = tamponade, stabilization, embolization; Initial stabilization = sheet application, **pelvic binder**, PCCD, external fixator, C-clamp, MAST; Acetabular fracture ดู **Judet view**

*Hip dislocation* [สไลด์]: Posterior = adduction, flexion, internal rotation; **Emergency reduction < 6 hr** (GA); Post-reduction ต้องเช็ค **sciatic nerve test**; skin traction 7–10 d

*Hip fracture* [สไลด์]: Goal = **early ambulation**; Non-displaced intracapsular → fixation in situ; Displaced intracapsular → มักทำ arthroplasty (เสี่ยง AVN สูง) [จริง]; Extracapsular → DHS/PFNA หรือ nail

*Femoral shaft/Patella/Tibial plateau/Knee dislocation* [สไลด์]: Femoral shaft → intramedullary nailing [จริง]; Patella displacement <3mm+articular<2mm → cast 4-6 wk, มากกว่า → tension band; Tibial plateau associated injuries = popliteal artery, peroneal nerve, compartment syndrome; Knee dislocation เสี่ยง neurovascular injury สูง

*Tibial shaft fracture* [สไลด์]: Long leg cast 4–6 wk (NWB) → PTB cast 4–6 wk (PWB); Acceptable reduction <5° coronal, <10° sagittal, <10° rotational, <1cm shortening

*Ankle & Foot* [สไลด์]: **Ottawa Ankle Rules** — bone tenderness 6 cm ของ distal fibula/tibia หรือเดินลงน้ำหนักไม่ได้ 4 ก้าว; Talar neck fracture → AVN สูง; Calcaneus **Bohler angle 20–40°, Gissane's angle 105–135°**

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| Open fracture antibiotic timing | ≤24 ชม.; I/II=ceph1, III=+aminoglycoside, ดิน=+penicillin [สไลด์] |
| ABI ปกติ/ผิดปกติ | > 0.9 ปกติ, < 0.9 ผิดปกติ [สไลด์] |
| Compartment ΔP | DBP − compartment ≤ 30 mmHg [สไลด์] |
| FES อาการ | 24–72 ชม. หลังบาดเจ็บ, เกิด 2–5% [สไลด์] |
| Gurd criteria | 2 major หรือ 1 major+4 minor [สไลด์] |
| Hip dislocation reduction | < 6 ชม. [สไลด์] |
| Ottawa Ankle Rules | 6 cm tenderness หรือเดิน 4 ก้าวไม่ได้ [สไลด์] |
| Calcaneus Bohler angle | 20–40° [สไลด์] |
| Calcaneus Gissane's angle | 105–135° [สไลด์] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. Hard signs 6P มีแค่ 6 ตัวเท่านั้น — อย่าสับสนกับตัวเลข P อื่น [สไลด์]
2. ABI cutoff = 0.9 (ไม่ใช่ 0.8 หรือ 1.0) [สไลด์]
3. Priority: stable→vascular ก่อน, unstable→ortho ก่อน, delayed→temporary shunt [สไลด์]
4. FES ต้อง "2 major หรือ 1 major+4 minor" ตาม Gurd — เกณฑ์ผสมกันได้ 2 แบบ [สไลด์]
5. Hip dislocation ต้อง reduce **<6 ชม.** (ยิ่งเร็วยิ่งลด AVN) — incongruent ไม่ใช่ emergency [สไลด์]
6. Talar neck fracture = AVN สูง ต้องผ่าตัดเกือบทุกครั้ง [สไลด์]
7. Tibial plateau เสี่ยง popliteal artery + peroneal nerve + compartment syndrome พร้อมกัน 3 อย่าง [สไลด์]
8. Bohler angle (20-40°) vs Gissane's angle (105-135°) เป็นคนละมุม อย่าจำสลับ [สไลด์]

## 7) GI Surgical Staple — ข้อ 49–52 (4 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-02-bariatric-stapling.md` + `lecture-notes/2026-09-02-periop-GI-MIS.md` (Session A, พว.วทัญญู ตาเวียรชัย)

**เข้าใจง่ายก่อน:** วิชานี้พูดถึงเครื่องมือเย็บอวัยวะ (Surgical Stapler) ที่มาแทนการเย็บมือ เพราะเร็วกว่าและรั่วซึมน้อยกว่า หัวใจสำคัญคือ **"หลักการตัวบี" (B-Shape)** — เวลาลวดเย็บปิดสนิทจะเป็นรูปตัว B ซึ่งบีบเนื้อเยื่อพอดี ไม่แน่นไม่หลวมเกินไป ทำให้เลือดยังไปเลี้ยงขอบแผลได้ (ไม่ตาย) และไม่รั่ว หัวใจเรื่องที่สองคือ "สีตลับลวด" ต้องเลือกให้ตรงกับความหนาเนื้อเยื่อ (บาง→หนา) แล้วเรื่องที่สามคือการดูแลผู้ป่วยผ่าตัดลดน้ำหนัก (Bariatric) แบบ step-by-step ตาม Day 0-1-2

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*ทำไมต้องใช้ Stapler* [สไลด์]: Hand Sutured เสี่ยง Leakage; Stapler เร็วกว่า (Significantly Quicker) + ปลอดภัยกว่า (Security against leaks)

*วิวัฒนาการ* [สไลด์]: 1940 เริ่มพัฒนาในสหภาพโซเวียต → 1960s แพร่หลายทั่วโลก → **1978 Ethicon เปิดตัว disposable stapling device ตัวแรก**

*หลักการ "ตัวบี" (B-Shape Principle)* [สไลด์] — เป้าหมาย 3 ข้อ: (1) **Tissue Compression** — บีบพอดี ไม่แน่นเกิน (2) **Avoiding Leakage/Fistula formation** — ป้องกันรั่วซึม (3) **Preserve Vascularization** — ช่องว่างตัว B ให้เลือดยังไปเลี้ยงขอบแผลได้ ไม่ตาย
- Staple anatomy: Crown (ส่วนบน), Leg (ขา), Closed = รูปตัว B; Unacceptable conditions: Misdirected legs, Non-conforming shape
- Staple Lines: 30-mm Vascular Linear = **3 แถวสลับฟันปลา**; 30-mm Linear มาตรฐาน = **2 แถวสลับฟันปลา**

*การเลือกสีตลับลวด (Cartridge Colors)* — **⚠️ ต้นทางมี 2 ตารางไม่ตรงกัน ต้องจำทั้งสองแบบแยกไฟล์:**

จากไฟล์ `bariatric-stapling.md` (4 สี, ไม่มีตัวเลข mm) [สไลด์]:
| สี | ความหนาเนื้อเยื่อ |
|---|---|
| ขาว (White) | บางมาก (Vascular) — เส้นเลือด |
| ฟ้า/น้ำเงิน (Blue) | ปกติ (Standard) — กระเพาะ/ลำไส้ทั่วไป |
| เขียว (Green) | หนา (Thick) — กระเพาะส่วนหนา |

*Safety Checklist 4 ข้อก่อนยิง Stapler (เรียงลำดับ)* [สไลด์]: (1) Examine & Assemble — เช็คความพร้อม (2) Seat Cartridges — ใส่ตลับลวด (3) Clear Obstructions — เคลียร์พื้นที่ (คลิป/สาย Bougie) (4) Firing Forces — กะแรงบีบ

*4 หมวดเครื่องมือเย็บ* [สไลด์]: Circular Staplers (end-to-end anastomosis), Linear Staplers (straight line), Linear Cutting Staplers (เย็บ+ตัดพร้อมกัน), Ligating and Skin Staplers

*Robotic Staplers* [สไลด์]: du Vinci Xi มี **SmartClamp Technology** ตรวจจับความหนาเนื้อเยื่อก่อนยิง

*แนวปฏิบัติความปลอดภัยหลังยิง (4 ข้อ)* [สไลด์]: Verify Compatibility (สีตลับตรงความหนา) → Monitor the Mechanism → Inspect the Staple Line (B-Shape สมบูรณ์ + tissue "donuts" ครบในเครื่องมือวงกลม) → Always Prepare Backup

*ชนิดหัตถการ Bariatric Surgery* [สไลด์]: Sleeve Gastrectomy (ตัดกระเพาะบางส่วน), Roux-en-Y Gastric Bypass; เกณฑ์ผู้ป่วย (NIH Guideline): **BMI > 40** หรือ **BMI > 35 พร้อมโรคร่วม**

*Clinical Pathway Bariatric Day 0–2* [สไลด์]
- **Day 0:** NPO, Acetar 1000 ml IV (120 ml/h); Morphine 2mg IV prn q2hr, Ondansetron, Omeprazole, Ceftriaxone, Metronidazole; Notify ถ้า BP<90/60, PR>120, O2<90%; POCT q6hr คุม 80-200 mg%; **Heparin 5000 unit SC เริ่มที่ 6 ชม.หลังผ่าตัด** (ถ้าไม่มี Bleeding); Sequential compression device
- **Day 1:** Early ambulation; Clear liquid diet 600-800 kcal/day (No sugar, Low fat, High protein); Off Foley, Wean off O2 (ถ้า O2sat>90%); **ยาทุกชนิดต้องบดละเอียด+ผสมน้ำก่อนกิน นาน 3 เดือน** หลังผ่าตัด (ป้องกันอุดตันกระเพาะที่เย็บใหม่)
- **Day 2/Discharge:** Liquid diet ต่ออีก **2 สัปดาห์**; **กฎ 5 ข้อ**: (1) งดของหวาน/ป้องกัน Dumping Syndrome (2) เคี้ยวช้าๆละเอียด (3) กินแค่ 1 ถ้วย (4) ห้ามกักตุนอาหาร (5) จดบันทึกทุกอย่างที่กิน

*ERAS สำหรับ Bariatric* [สไลด์]: Discharge Planning Starts on Day 1, Multidisciplinary Team, สอนโภชนาการ+wound care+functional needs

6. NIH criteria: BMI>40 **หรือ** BMI>35+โรคร่วม (ไม่ใช่ "และ") [สไลด์]

## 8) THA (Total Hip Arthroplasty) — ข้อ 53–56 (4 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-04-tha-perioperative-ortho.md` (พว.มนันพัทธ์ ทองบุญเกื้อ, สไลด์ 39 หน้า)

**เข้าใจง่ายก่อน:** THA คือการผ่าตัดเปลี่ยนข้อสะโพกเทียม ประเด็นหลักที่ออกสอบมี 2 กลุ่ม: (1) **เทคนิคผ่าตัด** — วิธียึดข้อเทียม (cement vs cementless) และแนวทางเข้าแผล (4 approaches ที่แต่ละแบบเสี่ยงเส้นประสาทคนละเส้น) (2) **7 ปัญหาการพยาบาลหลังผ่าตัด** ที่มีเกณฑ์ตัวเลขชัดเจนแยกแต่ละปัญหา เช่น ปริมาณเลือดออกที่ต้องรายงาน, มุมกางขาป้องกันข้อเคลื่อนหลุด จำง่ายๆ ว่า Posterolateral (เห็นเบ้าชัด ไม่แตะ abductor) เสี่ยง sciatic nerve + dislocation ส่วน Anterior (ไม่ dislocation) เสี่ยง femoral nerve แทน

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*โรคข้อสะโพกที่นำไปสู่ THA* [สไลด์]: Osteonecrosis of femoral head, Primary hip OA, RA, Developmental dysplasia of hip, Femoral neck fracture; อาการ: ปวดเมื่อเดินลงน้ำหนัก ตำแหน่งขาหนีบ/ต้นขาด้านหน้า-ใน, ตรวจ Internal rotation เจ็บ, บางรายขาสั้นลง

*Type of Hip surgery* [สไลด์]
- **Hemiarthroplasty** — เปลี่ยนเฉพาะกระดูกต้นขา เวลา/เลือดออกน้อยกว่า มั่นคงสูง
- **THA** — เปลี่ยน acetabular cup + femoral head + femoral stem + acetabular liner; ผ่าตัดนาน เสียเลือดมากกว่า แต่แก้พยาธิสภาพได้ทั้งเบ้า+หัวต้นขา
- **Cemented (PMMA):** แข็งตัว **10–15 นาที**; ใช้ผู้สูงอายุ/กระดูกไม่ดี; ⚠️ ระวังโรคหัวใจ → กระตุ้นหัวใจ + **pulmonary embolism**
- **Cementless:** porous surface → osseointegration **6–8 สัปดาห์**; ใช้กระดูกแข็งแรงดี

*Skin incision — 4 approaches* [สไลด์]

| Approach | ข้อดี | ความเสี่ยง |
|---|---|---|
| **Anterior** | บาดเจ็บกล้ามเนื้อน้อย, **ไม่เกิด hip dislocation**, เห็นเบ้าดี | ใส่ femoral stem ยาก; เสี่ยง **femoral + lateral femoral cutaneous nerve** |
| Anterolateral | เห็นหัว+คอสะโพกดี | เสี่ยง superior gluteal nerve |
| Lateral | เห็นหัว+เบ้าดี | ต้องตัด hip abductor บางส่วน → อ่อนแรง; เสี่ยง superior gluteal nerve |
| **Posterolateral** | เข้าข้อง่าย เห็นเบ้าชัด, **ไม่บาดเจ็บ abductor** | เสี่ยง **sciatic nerve**; **มีโอกาส hip dislocation** |

*Complications in THA* [สไลด์]: Hip fracture, Vascular & nerve injury, Hip dislocation, VTE (DVT/PE), Wearing/loosening of prosthesis, Infection, Pulmonary embolism

*7 ประเด็นปัญหาทางการพยาบาล + เกณฑ์* [สไลด์]

| # | ปัญหา | เกณฑ์/สัญญาณ | การพยาบาลหลัก |
|---|---|---|---|
| 1 | วิตกกังวล | ไม่ทราบวิธีปฏิบัติตัว | ให้ข้อมูลก่อน/หลังผ่าตัด |
| 2 | ปวดแผล | pain score **>3** | NRS/face scale, **periarticular injection** |
| 3 | เสี่ยงเสียเลือด/ช็อก | **intraop bleed >500 cc / drain >200 cc/hr**, SBP<90/P>100 | **Tranexamic acid** |
| 4 | เสี่ยง PE | **RR>30**, O2sat<95, กระสับกระส่าย | หัวสูง **45°**, O2 cannula **3 L/min** |
| 5 | เสี่ยง DVT | ขาบวมตึง ปวดน่อง | dorsalis pedis pulse, **IPCD** |
| 6 | เสี่ยง dislocation | ขาผิดรูป บิดหมุน, เส้นสั้น | นอนราบหัวสูง 30°, **กางขา 15–30°** หมอนคั่น |
| 7 | เสี่ยงติดเชื้อ | **T>37.5, ESR>20, CRP>5** | Sterile technique, ATB prophylaxis |

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| PMMA แข็งตัว | 10–15 นาที [สไลด์] |
| Cementless osseointegration | 6–8 สัปดาห์ [สไลด์] |
| เกณฑ์เลือดออก | intraop >500 cc / drain >200 cc/hr [สไลด์] |
| เกณฑ์ PE | RR>30, O2sat<95 [สไลด์] |
| จัดท่า PE | หัวสูง 45°, O2 3 L/min [สไลด์] |
| กางขาป้องกัน dislocation | 15–30° [สไลด์] |
| เกณฑ์ติดเชื้อ | T>37.5, ESR>20, CRP>5 [สไลด์] |
| Pain score เกณฑ์ | >3 [สไลด์] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. Anterior = ไม่ dislocation แต่เสี่ยง femoral nerve; **Posterolateral = เสี่ยง sciatic + dislocation** แต่ไม่แตะ abductor — จำสลับกันบ่อย [สไลด์]
2. Cement (PMMA) เกี่ยวข้องกับ **pulmonary embolism** โดยเฉพาะผู้ป่วยโรคหัวใจ — จุดที่มักลืม [จริง]
3. เกณฑ์เลือดออก (500 cc / 200 cc/hr) กับเกณฑ์ PE (RR>30/O2sat<95) เป็นตัวเลขข้อสอบบ่อยที่สุดในหัวข้อนี้ [สไลด์]
4. Dislocation prevention หลัก posterolateral = หลีกเลี่ยง **hip flexion >90°, adduction, internal rotation** ข้ามเส้นกึ่งกลาง [จริง]
5. PMMA แข็งตัว 10-15 นาที vs Cementless osseointegration 6-8 **สัปดาห์** — หน่วยเวลาต่างกันมาก (นาที vs สัปดาห์) [สไลด์]

## 9) TKA (Total Knee Arthroplasty) — ข้อ 57–60 (4 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-04-tka-perioperative-ortho.md` (พว.ศิริชล เนตรสว่าง, สไลด์ 31 หน้า)

**เข้าใจง่ายก่อน:** TKA คือการผ่าตัดเปลี่ยนข้อเข่าเทียมทั้งข้อ วิชานี้เน้น "เส้นทางการดูแลผู้ป่วยตามลำดับเวลา" ตั้งแต่ก่อนมาโรงพยาบาล (Pre-Admission) → ประเมินก่อนผ่าตัด → เตรียมห้องผ่าตัด → ระหว่างผ่าตัด → เกณฑ์เคลื่อนย้ายออกจากห้องผ่าตัด (มีตัวเลขชัดเจน) → ส่งเวรหลังผ่าตัดด้วย verbal report 9 หัวข้อ จำง่ายๆ ว่า TKA งอได้ 125-130° และเกณฑ์เคลื่อนย้าย SpO2>98%/O2 5L/min เป็นตัวเลขที่ออกสอบบ่อยที่สุด

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*ภาพรวม TKA* [สไลด์]: femoral, tibial, patellar component + polyethylene insert; งอได้ **125–130 องศา**; Mobile bearing (เคลื่อนได้เลียนแบบธรรมชาติ); MIS-TKA (แผลเล็ก)
- Risk factors ข้อเข่าเสื่อม: Arthritis, Age, Sex, **Obesity**, genetic, repetitive knee injury
- ตัวอย่าง Arthritis ในสไลด์: Rheumatoid arthritis (pannus formation), Gout knee (uric acid สะสม)
- การรักษา: Conservative (PT+NSAIDs) → Surgical (Unicompartmental เปลี่ยนบางส่วน vs Total เปลี่ยนทั้งข้อ)

*ระยะการพยาบาล* [สไลด์]
1. **Pre-Admission nurse** — ประเมิน/เตรียมข้อมูลก่อนมา รพ., ลดวิตกกังวล; ภาพประกอบ CXR, lab, EKG, X-ray เข่า weight-bearing
2. **Preoperative assessment** — CBC/coagulogram/BUN-Cr/UA, ประเมินความเสี่ยง (HT/DM/CAD/ไต, BMI, anticoagulant), ID band/Consent form; **ยาที่เตรียมจริง:** Cefazolin 1g (ATB prophylaxis), Tranexamic acid (ลดเลือดออก), Marcaine (Bupivacaine) 0.5% (ยาชา periarticular), Ketorolac (NSAID ฉีด)
3. **OR preparation** — sterility/laminar flow/positive pressure; **Prophylactic antibiotic ภายใน 60 นาทีก่อน incision** (redose หลัง 3–4 ชม./เสียเลือดมาก)
4. **Intra-operative phase** — WHO Surgical Safety Checklist (Sign in/Time out/Sign out); ลำดับ: skin prep → tourniquet → draping → cutting block/oscillating saw → implant trial/จริง → bone cement → ทดสอบ ROM → ปิดแผล
5. **การเคลื่อนย้ายออกจากห้องผ่าตัด** — เกณฑ์ **SpO₂ > 98%** และ **O₂ 5 L/min**
6. **Post-operative Care — Verbal report 9 หัวข้อ:** Patient's identification, Operation, Side, Allergy, Vital signs, Anaesthetic, IV fluid, Bleeding, Urine

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| TKA งอได้ | 125–130° [สไลด์] |
| เกณฑ์เคลื่อนย้ายออกจากห้องผ่าตัด | SpO₂ > 98%, O₂ 5 L/min [สไลด์] |
| Prophylactic antibiotic timing | ภายใน 60 นาทีก่อน incision, redose 3-4 ชม. [เสริม/จริง] |
| Verbal report | 9 หัวข้อ (ID, Operation, Side, Allergy, VS, Anesthetic, IV fluid, Bleeding, Urine) [สไลด์] |
| ยาที่ใช้จริง | Cefazolin 1g, Tranexamic acid, Marcaine 0.5%, Ketorolac [สไลด์] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. เกณฑ์เคลื่อนย้าย **SpO₂>98%, O₂ 5 L/min** — ตัวเลขข้อสอบบ่อยที่สุดของหัวข้อนี้ [สไลด์]
2. Verbal report ต้องเรียง 9 หัวข้อให้ครบตอนส่งเวร — ข้อสอบอาจถามว่าขาดหัวข้อใด [สไลด์]
3. TKA งอ 125–130° — อย่าสับสนกับตัวเลขอื่นของ THA (ซึ่งไม่มีตัวเลของศาการงอกำกับ) [สไลด์]
4. แยกบทบาทยา: Marcaine=ยาชาเฉพาะที่, Tranexamic acid=ลดเลือดออก, Cefazolin=ATB prophylaxis, Ketorolac=NSAID ลดปวด — คนละหน้าที่กัน [สไลด์]
5. Unicompartmental (เปลี่ยนบางส่วน/ข้อเดียว) vs Total (ทั้งข้อ) — อย่าสับสนคำ [สไลด์]
6. อย่าสับสน TKA (ข้อเข่า) กับ THA (ข้อสะโพก) — งอ 125-130° เป็นของเข่าเท่านั้น [จริง]

## 10) CHD surgery (Congenital Heart Disease) — ข้อ 61–72 (12 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-02-congenital-heart-disease-combined.md` (สไลด์ รศ.นพ.เกรียงไกร ตันติวงศ์โกสีย์ + transcript คาบเรียนจริง)

**เข้าใจง่ายก่อน:** โรคหัวใจพิการแต่กำเนิดแบ่งเป็น 3 กลุ่มตามทิศทางการไหลของเลือด — **Acyanotic** (เลือดไหลซ้าย→ขวา ยังมีออกซิเจน ไม่เขียว แต่เลือดท่วมปอด เช่น ASD/VSD/PDA), **Cyanotic** (เลือดไหลขวา→ซ้ายหรือผสมกัน เขียว เช่น TOF/TGA), **Obstructive** (มีจุดตีบ เลือดไม่ผสมกันเลย แต่หัวใจต้องออกแรงมากขึ้น เช่น Coarctation of aorta) จำง่ายๆ ว่า **Closed heart surgery กับ Open heart surgery แบ่งกันด้วยการใช้เครื่องปอด-หัวใจเทียม (CPB) เป็นหลัก ไม่ใช่แบ่งตาม "เปิด/ไม่เปิด" หน้าอกหรือหัวใจ** — ใช้ CPB = Open, ไม่ใช้ CPB = Closed หัวใจเด็กที่ผิดปกติรุนแรงมาก (เช่น HLHS ที่ไม่มีทาง 4 ห้องทำงานได้จริง) ต้องผ่าตัด "ทำให้ผิดปกติต่อไปอีก" เป็น 3 ขั้นตอน (Norwood→Glenn→Fontan) เพื่อให้เด็กรอดชีวิต

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*การจำแนก CHD 3 กลุ่ม* [สไลด์/คาบ]
- **Acyanotic** — left-to-right shunt, ไม่เขียวระยะแรก แต่เกิด pulmonary overcirculation/CHF: ตัวอย่าง ASD, VSD, PDA, AVSD
- **Cyanotic** — right-to-left shunt/mixing lesion: ตัวอย่าง TOF, TGA, Tricuspid Atresia, TAPVR, Truncus Arteriosus, HLHS; กลุ่มนี้แม้มีรูเชื่อมแต่มี **pulmonary stenosis รุนแรงร่วมด้วย** ทำให้เลือดลัดไป aorta แทนที่จะไปปอด [คาบ]
- **Obstructive** — ตีบ/อุดกั้นลิ้น/หลอดเลือดใหญ่ เลือด**ไม่ปนกันเลย**: Coarctation of Aorta, Aortic/Pulmonary Stenosis, Interrupted Aortic Arch

*Closed vs Open Heart Surgery* [สไลด์/คาบ] — **จุดออกสอบสำคัญที่สุดของวิชานี้**

| ประเด็น | Closed Heart Surgery | Open Heart Surgery |
|---|---|---|
| นิยาม | **ไม่ใช้ CPB** | **ใช้ CPB** (Cardiopulmonary Bypass) |
| แผล | มักเป็น thoracotomy | มักเป็น median sternotomy |
| หัวใจขณะผ่าตัด | ยังเต้นปกติ | หยุดเต้นด้วย cardioplegia |
| ตัวอย่าง | PDA ligation, MBTS, Coarctation repair, PA banding | ASD/VSD closure, TOF repair, AVSD repair, Norwood, Fontan |

> "Close Heart Surgery กับ Open Heart **ไม่ใช่** เปิดกับปิดหัวใจ — แบ่งกันตรงที่ใช้ Heart-Lung Machine หรือไม่" [คาบ]

*หัตถการ Closed Heart Surgery* [สไลด์]
- **PDA Ligation:** เข้าทาง (posterolateral) thoracotomy, ligation ด้วย clip/ไหมสองชั้น; เสี่ยง **recurrent laryngeal nerve injury** (เสียงแหบ) [จริง]; ความดัน aorta สูงกว่า PA ~**4 เท่า** ทำให้เลือดท่วมปอดถ้าไม่ปิด [คาบ]
- **MBTS (Modified Blalock-Taussig Shunt):** ใช้ **Gore-Tex graft** เชื่อม subclavian artery → pulmonary artery; เป็น palliative shunt เพิ่มเลือดไปปอดในผู้ป่วย cyanotic; เสี่ยง **shunt thrombosis** ช่วง 24-48 ชม.แรก; ปัจจุบันเปลี่ยนชื่อเป็น "Blalock-Taussig-**Thomas** Shunt" ให้เกียรติ Vivien Thomas ผู้คิดค้นเทคนิคจริง [คาบ]
- **Coarctation of Aorta Repair:** เข้าทาง left posterolateral thoracotomy; **Resection with end-to-end anastomosis** (นิยมที่สุด) หรือ subclavian flap/patch aortoplasty; ระวัง **postoperative hypertension** และ spinal cord ischemia
- **PA Banding:** รัด band รอบ main PA ลดเลือดไปปอด — ใช้เมื่อ (1) VSD ใหญ่/ตำแหน่งปิดยาก หรือ (2) มี **sepsis/infection** (ขึ้น CPB ไม่ได้เพราะเสี่ยงเสียชีวิต) หรือมีข้อห้าม heparin [คาบ]

*Cardiopulmonary Bypass (CPB)* [สไลด์/คาบ]
- องค์ประกอบ: Venous cannula → Venous reservoir → **Oxygenator** (แทนปอด) → Heat exchanger → **Pump** (แทนหัวใจ) → Arterial cannula กลับเข้าผู้ป่วย; **Aortic cross-clamp** + **Cardioplegia** (potassium สูง, เย็น **4°C**) ทำให้หัวใจหยุดเต้น
- ลำดับขั้นตอน: **Heparin ก่อนเสมอ** → cannulate → cross-clamp+cardioplegia → ผ่าตัด → **de-airing** (เช็คด้วย echo) → ปล่อย cross-clamp → rewarm → wean off → decannulate + **protamine** (reverse heparin)
- **Heart-Lung Machine มีหน้าที่ 4 อย่าง:** แทนปอด, แทนหัวใจ, คูล/วอร์มร่างกาย, **แทนไตได้ด้วย** (ต่อเครื่องฟอกไต) [คาบ]
- **Cross-clamp time หัวใจทนได้ ~4 ชั่วโมง** (กลางๆ, สั้นกว่าดีกว่า, ยาวถึง 6-7 ชม.เสี่ยงมาก) [คาบ]
- **DHCA (Deep Hypothermic Circulatory Arrest):** คูลร่างกายลงไปที่ **15°C**, ติด EEG ศีรษะ, **สมองทนหยุดไหลเวียนสนิทได้ ~30 นาที** [คาบ]

*หัตถการ Open Heart Surgery* [สไลด์]
- **ASD Closure:** ชนิด Ostium secundum (พบบ่อยสุด ~70%), Ostium primum (ร่วมกับ AVSD spectrum), Sinus venosus (ร่วมกับ PAPVR); ปิดผ่าน right atriotomy ด้วย direct suture/patch; **ASD เป็นโรคที่ผ่าตัดง่ายที่สุดในบรรดา CHD** [คาบ]
- **VSD Closure:** ชนิด Perimembranous (พบบ่อยสุด ~80%), Muscular, Supracristal (เสี่ยง AR), Inlet; เข้าถึงผ่าน right atriotomy/trans-tricuspid approach; ระวัง **conduction system (AV node/Bundle of His)** อยู่ใกล้ perimembranous VSD — เย็บผิดเสี่ยง **complete heart block**; บางรายปิดเองได้/ปิดด้วย transcatheter device
- **AVSD/CAVC:** ผิดปกติของ endocardial cushion → Primum ASD + Inlet VSD + **Common AV valve**; พบบ่อยใน **Down syndrome** [จริง]; ต้องทำ Single/Two-patch technique + septate valve; "ยากขึ้นไปอีก" กว่า ASD/VSD เพราะไม่มีผนังกั้นทั้งบน-ล่าง [คาบ]
- **TOF (Tetralogy of Fallot)** — **cyanotic heart disease ที่พบบ่อยที่สุด** [คาบ]; 4 องค์ประกอบ: **VSD, Pulmonary Stenosis (RVOTO), Overriding Aorta, RVH**; ซ่อมโดยปิด VSD + ขยาย RVOT; เลือก **Transannular patch** (ตัดผ่าน annulus, แก้ obstruction ได้เต็มที่แต่เสี่ยง **pulmonary regurgitation เรื้อรัง**) vs **Non-transannular patch** (คง valve ไว้ได้ถ้า annulus พอ, ผลลัพธ์ระยะยาวดีกว่า)
- **HLHS (Hypoplastic Left Heart Syndrome):** LV/mitral/aortic valve เล็กมาก ทำหน้าที่ไม่ได้ → ต้องพึ่ง **ductal-dependent systemic circulation** ผ่าน PDA (ให้ **prostaglandin E1** คง PDA เปิด) ถ้า PDA ปิด = เทียบเท่า cardiac arrest [คาบ]

*Staged Single-Ventricle Palliation (สำหรับ HLHS)* [สไลด์/คาบ] — **ลำดับต้องจำแม่น**

| Stage | หัตถการ | ช่วงอายุ | หลักการ |
|---|---|---|---|
| 1 | **Norwood** (+BT shunt หรือ Sano shunt) | **ภายในเดือนแรกของชีวิต** | สร้าง neoaorta, atrial septectomy, สร้างทางเลือดไปปอดใหม่ |
| 2 | **Bidirectional Glenn shunt** | **4-6 เดือน** (หรือ 4/6/8) | เชื่อม SVC→PA โดยตรง, ถอด shunt เดิม |
| 3 | **Fontan procedure** | **~2 ปีขึ้นไป** | เชื่อม IVC→PA เพิ่ม (Total Cavopulmonary Connection) |

- **BT shunt vs Sano shunt (ใน Norwood):** BT shunt (systemic artery→PA) มี **diastolic runoff** ลด diastolic BP/coronary perfusion; Sano shunt (RV→PA conduit) ไม่มี diastolic runoff แต่ต้องเจาะ RV (ventriculotomy)
- เหตุผลทำ staged แทนซ่อมครั้งเดียว: "เราจึงต้องทำให้มันผิดปกติขึ้นไปอีก เพื่อความอยู่รอด" [คาบ] — เพราะไม่มีทางทำให้มี 4 ห้องทำงานปกติได้จริง

*ECMO (Extracorporeal Membrane Oxygenation)* [สไลด์/คาบ]
- ต่างจาก CPB ตรงที่ใช้งาน**ระยะยาว** (วัน-สัปดาห์) ไม่ใช่แค่ระหว่างผ่าตัด
- ชนิด: **VA ECMO** (สนับสนุนหัวใจ+ปอด) vs **VV ECMO** (สนับสนุนปอดอย่างเดียว)
- Cannulation: Central (RA+ascending aorta, กรณี post-cardiotomy) vs Peripheral (คอ หรือ ขาหนีบ); **เด็กน้ำหนัก < 2.5 กก. ต้องใส่ที่คอ (carotid+internal jugular)** เพราะเส้นเลือดขาเล็กเกินไป [คาบ]

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| ความดัน aorta vs PA ใน PDA ที่เปิดค้าง | สูงกว่า ~4 เท่า [คาบ] |
| Cardioplegia อุณหภูมิ | 4°C [คาบ] |
| Cross-clamp time หัวใจทนได้ | ~4 ชั่วโมง (กลางๆ) [คาบ] |
| DHCA อุณหภูมิร่างกาย | 15°C [คาบ] |
| DHCA สมองทนหยุดไหลเวียนได้ | ~30 นาที [คาบ] |
| Norwood ต้องทำภายใน | เดือนแรกของชีวิต [คาบ] |
| Bidirectional Glenn ช่วงอายุ | 4-6 เดือน (หรือ 4/6/8) [คาบ] |
| Fontan ช่วงอายุ | ~2 ปีขึ้นไป [สไลด์/คาบ] |
| ASD ชนิดที่พบบ่อยที่สุด | Ostium secundum ~70% [เสริม/จริง] |
| VSD ชนิดที่พบบ่อยที่สุด | Perimembranous ~80% [เสริม/จริง] |
| ECMO ใส่ที่คอเมื่อเด็กหนักน้อยกว่า | 2.5 กก. [คาบ] |
| Congenital heart disease พบได้ | ร้อยละ 1 ของประชากร [สไลด์: cardiothoracic] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. **Closed vs Open heart surgery แบ่งด้วยการใช้ CPB เท่านั้น** ไม่ใช่แบ่งตามเปิด/ไม่เปิดหน้าอก — จุดที่นักศึกษาเข้าใจผิดบ่อยที่สุด [คาบ]
2. Cyanotic group แม้มีรูเชื่อม (VSD) แต่ต้องมี **pulmonary stenosis รุนแรงร่วมด้วย** จึงเขียว — ถ้ามีแค่ VSD อย่างเดียวไม่เขียว [คาบ]
3. BT shunt (diastolic runoff, ลด coronary perfusion) vs Sano shunt (ไม่มี runoff แต่ต้องเจาะ RV) — จำข้อดี-เสียให้ตรงข้าม [เสริม]
4. ลำดับ staged palliation ของ HLHS ต้องเรียงถูก: **Norwood (เดือนแรก) → Glenn (4-6 เดือน) → Fontan (2 ปี+)** [คาบ]
5. TOF: **Transannular patch** = แก้ obstruction เต็มที่แต่เสี่ยง PR เรื้อรัง; **Non-transannular** = คง valve ได้แต่ทำได้เฉพาะ annulus ไม่เล็กเกินไป [เสริม]
6. AVSD พบบ่อยใน **Down syndrome** — เชื่อมโยงกับความรู้กุมารเวชที่เคยเรียน [จริง]
7. Cross-clamp time (~4 ชม.) กับ DHCA circulatory arrest (~30 นาที) เป็นคนละตัวเลขคนละบริบท — DHCA สั้นกว่ามากเพราะไม่มีการไหลเวียนเลยแม้แต่น้อย [คาบ]
8. Heart-Lung Machine ทำหน้าที่ได้ถึง **4 อย่าง** (ปอด/หัวใจ/คูล-วอร์ม/ไต) — มักลืมข้อ "แทนไตได้ด้วย" [คาบ]

## 11) Heart & Aortic Disease — ข้อ 87–98 (12 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-11-heart-aortic-disease.md` (อ.นพ.อังศุธร ชาติรังสรรค์, สไลด์ 55 หน้า)

**เข้าใจง่ายก่อน:** วิชานี้คือโรคหัวใจที่เกิดภายหลัง (ไม่ใช่แต่กำเนิด) ในบริบท "ทุกห้องผ่าตัดต้องเจอผู้ป่วยโรคหัวใจ" เพราะสังคมสูงวัย หัวใจสำคัญคือสมการ **BP = HR × SV × SVR** ใช้อธิบายความดันตกได้เกือบทุกกรณี แล้วมีโรค 3 กลุ่มหลัก: หลอดเลือดหัวใจตีบ (CAD), ลิ้นหัวใจ (Valvular), หลอดเลือดแดงใหญ่ (Aortic) ประเด็นที่ออกสอบเยอะที่สุดคือ "ยาต้านลิ่มเลือดต้องหยุดกี่วันก่อนผ่าตัด" เพราะมีตารางตัวเลขละเอียดมาก ต้องจำแยกยาแต่ละตัว และ "หลังใส่ stent ต้องรอนานแค่ไหนก่อนผ่าตัด elective"

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*Basic heart anatomy & physiology* [สไลด์]
- หัวใจ 2 ปั๊ม 4 ห้อง 4 ลิ้น: RA→RV→ปอด→LA→LV→aorta; LV ผนังหนาสุด แรงดันสูงสุด
- **Coronary 3 เส้นหลัก** เลี้ยงเลือดหัวใจช่วง **diastole** เป็นหลัก: RCA (ผนังล่าง, SA/AV node → อุดตันทำหัวใจเต้นช้า), LAD (ผนังหน้าส่วนใหญ่ของ LV → "widow maker"), LCx (ผนังด้านข้าง)
- **สมการหลัก: BP = HR × SV × SVR** — Preload ต่ำ→เสียเลือด/ขาดน้ำ; Contractility ต่ำ→หัวใจล้มเหลว; Afterload สูง→ความดันสูง/AS, ต่ำ→sepsis/spinal block; HR เร็ว/ช้าเกิน→output ลด

*Coronary artery disease (CAD)* [สไลด์]

| ประเภท | ลักษณะ |
|---|---|
| Stable angina | เจ็บออกแรง หายใน 5–10 นาที |
| ACS: NSTEMI/unstable angina | เจ็บขณะพัก >20 นาที, troponin ขึ้น |
| STEMI | อุดตันสมบูรณ์, ST ยก, ต้อง PCI ทันที |

- ใต้ยาสลบบอกเจ็บไม่ได้ — สัญญาณคือ ST เปลี่ยน/ความดันตก/arrhythmia ใหม่
- รักษา 3 ทาง: ยา (aspirin/statin/beta-blocker) → PCI+stent (DAPT 6-12 เดือน) → CABG (3 เส้น/left main/DM/EF ต่ำ)
- CABG ใช้เส้นเลือดผู้ป่วยเอง: LIMA, saphenous vein, radial artery; แผลกระดูกอกติดใน **6-8 สัปดาห์**; หลีกเลี่ยงวัด BP/เจาะเลือดแขนที่เอา radial artery ไปใช้

*Valvular heart disease* [สไลด์]
- สาเหตุ: Rheumatic (อายุน้อย-กลางคน, มักมี AF), Degenerative (สูงอายุ), Infective endocarditis
- **Aortic stenosis — อายุขัยเฉลี่ยหลังเริ่มมีอาการ (ไม่รักษา):** angina 5 ปี, syncope 3 ปี, HF **2 ปี**
- ลิ้นเทียม 2 แบบ: **Mechanical** (warfarin ตลอดชีวิต, **ห้าม NOAC**) vs **Bioprosthetic** (ไม่ต้อง warfarin ระยะยาว, เสื่อมใน 10-15 ปี)
- เทรนด์: **TAVI** (ผ่านขาหนีบ) — สปสช.เริ่มให้สิทธิ์แล้ว

*Heart failure* [สไลด์]
- แบ่งตาม EF: **HFrEF ≤40%, HFmrEF 41-49%, HFpEF ≥50%**
- NYHA: I ไม่มีอาการ, II เหนื่อยกิจกรรมปกติ, III เหนื่อยกิจกรรมเล็กน้อย, IV เหนื่อยขณะพัก
- บันไดรักษา: ยา → อุปกรณ์ (CRT, ICD) → Temporary MCS (IABP, Impella, ECMO) → LVAD → Heart transplant
- **SGLT2 inhibitor ต้องหยุด 3 วันก่อนผ่าตัด** (เสี่ยง euglycemic DKA)

*Aortic disease* [สไลด์]
- 3 แบบ: aneurysm (โป่ง, ไม่มีอาการส่วนใหญ่), dissection (ปริ/ฉีกเซาะ, เจ็บทันทีรุนแรง), rupture (แตก, เสียชีวิตเร็ว)
- เกณฑ์ผ่าตัด: ขนาดทั่วไป (ascending/descending, AAA ชาย) **5.5 cm**; เล็กลง (AAA หญิง, Marfan) **5.0 cm**; โตเร็ว **≥0.5 cm/ปี**; มีอาการ = ผ่าตัดทุกขนาด
- **Dissection: Stanford A** (เกี่ยว ascending) → ผ่าตัดฉุกเฉินทันที, ไม่ผ่าตัดเสียชีวิต **~1-2%/ชม.**; **Stanford B** (ไม่เกี่ยว ascending) → คุมด้วยยา, TEVAR ถ้ามีภาวะแทรกซ้อน
- เป้าหมายก่อนผ่าตัด type B: ชีพจร **<60**, SBP **100-120 mmHg**
- Red flags dissection: ปวดทันทีรุนแรงที่สุด, BP แขน 2 ข้างต่าง **>20 mmHg**, ชีพจรคลำไม่ได้, tamponade

*บทบาท OR nurse — ก่อนผ่าตัดผู้ป่วยโรคหัวใจ* [สไลด์]
- 4 คำถาม: ฉุกเฉินไหม? → โรคหัวใจกำเริบไหม (ACS/HF กำเริบ/arrhythmia ไม่คงที่ → เลื่อน)? → ผ่าตัดเสี่ยงแค่ไหน? → ผู้ป่วยแข็งแรงแค่ไหน (**≥4 METs** = ขึ้นบันได 2 ชั้นไม่เหนื่อย → ผ่าตัดได้)?
- Surgical risk 30 วัน: Low <1% (ตา/เต้านม/TURP เล็ก), Intermediate 1-5% (ช่องท้อง/สะโพก/EVAR), High >5% (aorta/esophagus/liver/amputation)
- Holding area หยุดก่อน: เจ็บหน้าอกใหม่, ชีพจร>120, **BP ≥180/110 mmHg**

*ยาต้านลิ่มเลือด — หยุดก่อนผ่าตัด* [สไลด์] — **หัวข้อออกสอบเยอะที่สุด**

| ยา | หยุดก่อนผ่าตัด |
|---|---|
| Aspirin | ส่วนใหญ่ไม่หยุด (หยุด 7 วันเฉพาะผ่าตัดสมอง/ไขสันหลัง) |
| Clopidogrel | 5 วัน |
| Ticagrelor | 3-5 วัน |
| Prasugrel | 7 วัน |

- **หลังใส่ stent — รอก่อนผ่าตัด elective:** ≤30 วัน = ห้ามผ่าตัด; 3 เดือน = time-sensitive พิจารณาได้; **6 เดือน = stent จาก CCD → elective ได้; 12 เดือน = stent จาก ACS/MI → elective ได้**; balloon angioplasty อย่างเดียว รอ ≥14 วัน
- Warfarin: หยุด 5 วัน, เจาะ INR วันก่อนผ่าตัด เป้า <1.5; bridging เฉพาะกลุ่มเสี่ยงสูง (ลิ้นโลหะ mitral, ลิ้นโลหะ+AF/stroke, stroke<3 เดือน, VTE<3 เดือน)
- **NOAC/DOAC:**

| ยา | เลือดออกน้อย-ปานกลาง | เลือดออกสูง | Spinal/epidural |
|---|---|---|---|
| Apixaban/Rivaroxaban/Edoxaban | 1 วัน | 2 วัน | 3 วัน |
| Dabigatran (CrCl≥50) | 1 วัน | 2 วัน | 4 วัน |

- หลังผ่าตัดหัวใจ รอผ่าตัดโรคอื่น: ฟื้นตัว **6-8 สัปดาห์** (กระดูกอกยังไม่ติด), ~3 เดือน (ติดแล้ว), ปลอดภัยกว่าเมื่อรอ **≥100 วัน**

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| BP สมการ | HR × SV × SVR [สไลด์] |
| AS อายุขัยเฉลี่ย (angina/syncope/HF) | 5 ปี / 3 ปี / 2 ปี [สไลด์] |
| HF EF cutoffs | HFrEF≤40%, HFmrEF 41-49%, HFpEF≥50% [สไลด์] |
| SGLT2 inhibitor หยุดก่อนผ่าตัด | 3 วัน [สไลด์] |
| เกณฑ์ผ่าตัด aneurysm ทั่วไป/หญิง-Marfan | 5.5 cm / 5.0 cm [สไลด์] |
| โตเร็ว | ≥0.5 cm/ปี [สไลด์] |
| Stanford A mortality/ชม. | 1-2% [สไลด์] |
| Type B target BP/HR | SBP 100-120, HR<60 [สไลด์] |
| BP แขน 2 ข้างต่าง (red flag) | >20 mmHg [สไลด์] |
| METs ผ่าตัดได้ | ≥4 METs [สไลด์] |
| BP holding area ต้องหยุด | ≥180/110 mmHg [สไลด์] |
| Clopidogrel/Ticagrelor/Prasugrel หยุด | 5 วัน / 3-5 วัน / 7 วัน [สไลด์] |
| Stent CCD/ACS รอผ่าตัด elective | 6 เดือน / 12 เดือน [สไลด์] |
| Warfarin หยุด/INR เป้า | 5 วัน / <1.5 [สไลด์] |
| หลังผ่าตัดหัวใจ รอผ่าตัดอื่น | 6-8 สัปดาห์ (ห้าม) / ≥100 วัน (ปลอดภัยกว่า) [สไลด์] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. **หลังใส่ stent รอ 6 เดือน (CCD) vs 12 เดือน (ACS/MI)** — สลับกันบ่อยเพราะทั้งคู่เป็น "stent" [สไลด์]
2. Stanford A (ascending) = ฉุกเฉินทันที; Stanford B (ไม่เกี่ยว ascending) = คุมยาก่อน — จำผิดข้างได้ง่าย [สไลด์]
3. AS อายุขัยเฉลี่ยเรียงจากอาการเบาไปหนัก: angina 5 ปี > syncope 3 ปี > HF 2 ปี (ยิ่งอาการรุนแรงยิ่งอายุขัยสั้น) [สไลด์]
4. Mechanical valve **ห้าม NOAC** ต้องใช้ warfarin เท่านั้น — จุดตายที่ห้ามพลาด [สไลด์]
5. SGLT2 inhibitor หยุด 3 วัน (ป้องกัน euglycemic DKA) — ต่างจากยาเบาหวานทั่วไป [สไลด์]
6. NOAC หยุดตามระดับความเสี่ยงเลือดออก (1/2/3-4 วัน) ไม่ใช่ตัวเลขเดียวสำหรับทุกกรณี — ต้องดู bleeding risk category [สไลด์]
7. เกณฑ์ผ่าตัด aneurysm 5.5 cm (ทั่วไป) vs 5.0 cm (หญิง/Marfan) — เล็กกว่าในกลุ่มเสี่ยงสูง [สไลด์]
8. METs ≥4 = ขึ้นบันได 2 ชั้นไม่เหนื่อย = เกณฑ์ผ่าตัดได้ [สไลด์]

## 12) Periop Cardiothoracic — ข้อ 99–106 (8 ข้อ)

**แหล่ง:** `lecture-notes/2026-09-04-cardiothoracic.md` (พว.วิไลวรรณ อมรเดชเทวินทร์, สไลด์ 108 หน้า)

**เข้าใจง่ายก่อน:** วิชานี้คือภาพรวมการพยาบาลรอบผ่าตัดหัวใจ-ทรวงอกทั้งระบบ ตั้งแต่ชนิดการผ่าตัด (เปิด/ปิด), ชนิดโรค (แต่กำเนิด/ภายหลัง), เครื่องมือเฉพาะทาง, ไปจนถึงเครื่อง Heart-Lung Machine และอุปกรณ์ประคับประคองหัวใจ (LVAD/IABP/ECMO/BiVAD) ซึ่งต้องแยกแยะให้ออกว่าอุปกรณ์ไหนทำหน้าที่อะไร จำง่ายๆ ว่า Perioperative phase มี 3 ระยะเสมอ (pre/intra/post) ตาม AORN framework และวิชานี้เชื่อมโยงกับหัวข้อ CHD และ Heart & Aortic ที่เรียนมาแล้วในหลายจุด (เช่น ลิ้นหัวใจเทียม, aortic aneurysm)

**เนื้อหาที่ต้องรู้ (ครบถ้วน):**

*ชนิดการผ่าตัดหัวใจ + ชนิดโรค* [สไลด์]
- Cardiothoracic surgery แบ่ง 2 สาขา: Cardiac surgery และ Thoracic surgery
- ชนิดผ่าตัด: **Open heart surgery** (ใช้ CPB) และ **Closed heart surgery** (ไม่ใช้ CPB) — หลักการเดียวกับหัวข้อ CHD
- โรคหัวใจ 2 กลุ่ม: Congenital (แต่กำเนิด, **พบร้อยละ 1**) และ Acquired (ภายหลัง — coronary/valvular/aortic disease)
- แนวทางผ่าตัด congenital heart disease 3 แบบ: ผ่าตัดประคับประคอง / ประคับประคองก่อนแล้วแก้ไขทีหลัง / แก้ไขทั้งหมดในคราวเดียว

*Acquired heart disease* [สไลด์]
- 3 กลุ่ม: coronary heart disease, valvular heart disease, aortic disease
- วิธีรักษา CAD 3 ขั้น: **ยา → PCI → CABG**
- **Prosthetic valve 2 ชนิด:** **Mechanical** (Polycarbonate ทนทาน, เสี่ยง thrombo-embolism ต้องกิน anticoagulant ตลอดชีวิต) vs **Bioprosthetic** (Xenograft-หมู/วัว, Homograft-คน, Autograft-ตัวเอง; ไม่ต้องกินยาตลอดชีวิต เหมาะอายุ >65 ปีหรือตั้งครรภ์)
- Aortic aneurysm พบมากอายุ **50-80 ปี**, ผู้ชาย>ผู้หญิง; สาเหตุ atherosclerosis, บาดเจ็บ, อักเสบ, ซิฟิลิส, Marfan syndrome

*Thoracic surgery configuration (เฉพาะที่เกี่ยวกับ cardiothoracic setup)* [สไลด์]
- นิยาม: ผ่าตัดอวัยวะในช่องทรวงอก (หัวใจ, ปอด, trachea, esophagus, aorta, mediastinum)
- ปอด: ขวา **3 lobe**, ซ้าย **2 lobe**
- **Mediastinum แบ่ง 9 ส่วน**: Thymus gland, Pretracheal fat, deep to phrenic nerve, posterior to innominate vein, aortopulmonary window, aortocaval groove, anterior mediastinal fat, left/right cardiophrenic fat
- Special feature: ใช้ **double lumen endobronchial tube**
- Thoracoplasty แก้ไข pectus excavatum (อกบุ๋ม)/pectus carinatum (อกนูน)

*เครื่องมือเฉพาะทาง* [สไลด์]: เลื่อย Sternotomy, Retractor (Sternal/Rib spreader), Vascular clamps/forceps/scissors; OR configuration: Robot, Endovascular, Open heart, VATS

*Perioperative nursing care ตาม AORN framework* [สไลด์]
- **3 ระยะเสมอ:** pre-operative → intra-operative → post-operative
- มาตรฐานการปฏิบัติการพยาบาล **6 มาตรฐาน**: ประเมินผู้ป่วย, วินิจฉัยการพยาบาล, ระบุผลลัพธ์, วางแผนการพยาบาล, ปฏิบัติการพยาบาล, ประเมินผลการปฏิบัติ
- Nursing goal: Free from wrong patient/site/side, Free of anesthesia-related complication, Free of surgical position injury, Asepsis maintenance, Free of procedure-related complication, Free of anxiety

*Cardiopulmonary Bypass / Heart-Lung Machine* [สไลด์] — เนื้อหาซ้อนกับหัวข้อ CHD: ทำให้เกิด CPB ชั่วคราวขณะหัวใจ-ปอดหยุดทำงาน; การเตรียมสำหรับ Bypass มี 2 กรณี — cannulate ที่หลอดเลือดหัวใจโดยตรง หรือ cannulate ที่ femoral artery/vein

*อุปกรณ์ประคับประคองการไหลเวียนโลหิต/หัวใจ — ต้องแยกแยะ 4 ชนิด* [สไลด์]

| อุปกรณ์ | ชื่อเต็ม |
|---|---|
| LVAD | Left Ventricular Assist Device |
| IABP | Intra-Aortic Balloon Pump |
| ECMO | Extracorporeal Membrane Oxygenation |
| BiVAD | Biventricular Assist Device |

*Multidisciplinary team* [สไลด์]: Cardiology (medicine+surgery), Anesthesia (cardio anesthesiologist), Nurses (OPD/ward/OR/ICU), Perfusionist (ดูแล CPB)

**ตัวเลข/ค่าที่ต้องจำ:**

| รายการ | ค่า+ที่มา |
|---|---|
| Congenital heart disease พบได้ | ร้อยละ 1 [สไลด์] |
| แนวทางผ่าตัด congenital | 3 แบบ [สไลด์] |
| วิธีรักษา CAD | ยา → PCI → CABG [สไลด์] |
| Bioprosthetic valve เหมาะกับ | อายุ >65 ปี หรือตั้งครรภ์ [สไลด์] |
| Aortic aneurysm พบมากช่วงอายุ | 50-80 ปี, ชาย>หญิง [สไลด์] |
| ปอดขวา/ซ้าย จำนวน lobe | 3 lobe / 2 lobe [สไลด์] |
| Mediastinum แบ่ง | 9 ส่วน [สไลด์] |
| มาตรฐานการปฏิบัติการพยาบาล | 6 มาตรฐาน [สไลด์] |
| Perioperative phase | 3 ระยะ (pre/intra/post) [สไลด์] |

**จุดที่มักออกสอบ / ดักพลาด:**
1. Mechanical valve (ทนทาน แต่ต้องกิน anticoagulant ตลอดชีวิต) vs Bioprosthetic (ไม่ต้องกินยาตลอดชีวิต แต่เสื่อมเร็วกว่า) — จับคู่ข้อดี-ข้อเสียให้ถูก [สไลด์]
2. **LVAD/IABP/ECMO/BiVAD** ต้องแยกชื่อเต็มและหน้าที่ให้ถูก — ข้อสอบชอบถามจับคู่ตัวย่อกับชื่อเต็ม [สไลด์]
3. ปอดขวา 3 lobe, ปอดซ้าย 2 lobe (ไม่ใช่กลับกัน) [สไลด์]
4. Mediastinum แบ่ง **9 ส่วน** — ตัวเลขเฉพาะที่มักถูกถามตรงๆ [สไลด์]
5. Perioperative phase มี **3 ระยะเสมอ** (pre/intra/post) ตาม AORN — เชื่อมกับหัวข้อ Competency in OR ที่เรียนมาก่อน [สไลด์]
6. วิธีรักษา CAD ต้องเรียงลำดับ **ยา → PCI → CABG** (จากน้อยไปมาก ไม่ใช่สุ่มเลือก) [สไลด์]
7. Aortic aneurysm พบมากในอายุ 50-80 ปี ผู้ชายมากกว่าผู้หญิง — เชื่อมกับเกณฑ์ผ่าตัด 5.5cm/5.0cm ในหัวข้อ Heart & Aortic [สไลด์]
8. เนื้อหา thoracic surgery ในหัวข้อนี้เป็นแค่ "การจัดเตรียมห้องผ่าตัด cardiothoracic" ไม่ใช่เนื้อหา Thoracic System เต็มรูปแบบที่เลื่อนไปสอบครั้งที่ 2 — อย่าอ่านเกินขอบเขตที่สรุปนี้ให้ไว้
